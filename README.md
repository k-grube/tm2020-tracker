# tm2020-tracker

Deterministic screening of Trackmania 2020 ghost and replay files for the cheat signatures seen in the 2026 scandal plus the 2021 slow-motion method. Own Gbx parser, no runtime dependencies in the core, same code in a Node CLI and a static web page.

## Prior art
